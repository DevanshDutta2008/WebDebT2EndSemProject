# WebDebT2EndSemProject
End Term-2 Project

Student Expense Tracker
A comprehensive and visually appealing web-based expense tracking application designed specifically for students to manage their monthly budgets, track expenses, and monitor financial health.

Features
Core Functionality
Monthly Budget Management: Set and adjust monthly budgets with a default of ₹12,000

Transaction Tracking: Record both income and expenses with detailed categorization

Category Management: Pre-defined categories (Food, Transport, Academic, etc.) with individual budgets

Multi-Month Support: Navigate between months with persistent data for each period

Local Storage: All data persists locally in the browser

Financial Overview
Dashboard: Real-time overview of budget, spending, and remaining balance

Progress Tracking: Visual progress bars showing budget utilization

Category Insights: Individual category spending against allocated budgets

Monthly Trends: Historical view of income vs expenses over six months

Visualization
Interactive Charts:

Pie/Bar charts for expense distribution

Line charts for monthly trends

Responsive Design: Fully responsive interface that works on all devices

Dark/Light Mode: Toggle between themes for comfortable viewing

Data Management
Reset Function: Complete data reset with confirmation safeguards

Transaction Management: Add, view, and delete transactions

Budget Adjustment: Modify monthly budgets dynamically

Data Export/Import: Local storage with manual backup capability

Technology Stack
Frontend: HTML5, CSS3, Vanilla JavaScript

Charts: Chart.js with responsive design implementation

Icons: Font Awesome 6

Fonts: Google Fonts (Poppins)

Storage: Browser LocalStorage API
